# 课程整合验收

## 已覆盖的科学模型

30 个实验覆盖晶胞投影、布拉格角与立方点阵消光、一维倒格子、二维倒格子及前两区、两项幂势、一维马德隆级数、二维 Evjen、单/双原子链及振型、二维方向色散、德拜态密度与热容、点缺陷、平衡缺陷、Arrhenius、Fick、倾斜晶界间距、费米分布、费米球截面和电子态密度、铜参数、霍尔、低温金属热容、热发射、布洛赫波、局部近自由电子开隙、SC/FCC 紧束缚、有效质量、直接与间接带隙、掺杂、轻重空穴及满带响应。

二维 Evjen 二级结果用逐点权重求和，约 1.60687387。第 2 章交互规范中的 1.606782 落在其自身给出的 0.001 容差内，计算采用第 2 题的精确表达式。原稿保留原值。布里渊区的底色是离散采样，点的区序按不等式判定。少数原稿公式含中文数学标签，正常渲染时可见 KaTeX 的 Unicode 提示。课件自带的假设、勘误与边界说明仍随正文保留。
