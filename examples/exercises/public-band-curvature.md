# 速度相同的电子，有效质量也相同吗？

## 题目

一维紧束缚模型的色散为 $E(k)=-2J\cos(ka)$，其中 $J>0$、$a>0$。比较 $ka=\pi/3$ 与 $ka=2\pi/3$ 的群速度和有符号有效质量。用 $2Ja/\hbar$ 作为速度单位，用 $\hbar^2/(2Ja^2)$ 作为质量单位。

## 提示

群速度由一阶导数决定，逆有效质量由二阶导数决定。注意对 $k$ 求导时的链式法则。

## 展开推导与答案

归一化群速度为 $\sin(ka)$，两点的值都是 $\sqrt3/2$。归一化逆质量为 $\cos(ka)$，两点分别是 $+1/2$ 与 $-1/2$。

因此，归一化有效质量分别为 $+2$ 与 $-2$。群速度相同，但两点的能带曲率符号相反。
