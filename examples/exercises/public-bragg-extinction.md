# 有布拉格角就一定有衍射峰吗？

## 题目

一个常规立方晶胞的边长为 $0.48\,\mathrm{nm}$，用波长为 $0.12\,\mathrm{nm}$ 的 X 射线观察 $(210)$ 的一级反射。先求满足布拉格条件的散射角 $2\theta$。如果从简单立方改为体心立方，且所有原子相同，这个反射还允许吗？

## 提示

先用立方晶系的面间距关系计算 $d_{210}$。体心原子相对于角点原子的散射相位差与 $h+k+l$ 有关。

## 展开推导与答案

立方晶系的 $d_{210}=a/\sqrt{5}$，因此 $\sin\theta=\lambda/(2d_{210})=\sqrt{5}/8$，得到 $2\theta\approx32.46^\circ$。

简单立方的单原子基元没有这类几何消光。体心立方的常规胞中，中心原子在 $(1/2,1/2,1/2)$。对 $(210)$，两原子的散射振幅之和为 $f[1+\exp(i\pi(2+1+0))]=0$。体心立方在这一角度发生系统消光。
